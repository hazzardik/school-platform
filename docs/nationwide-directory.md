# Каталог населённых пунктов и школ: план расширения на всю Россию

**Статус реализации:** 89 субъектов в форме, неполный набор подсказок городов для 12 субъектов, 17 проверенных общеобразовательных организаций Невинномысска. Остальные населённые пункты и школы ещё НЕ импортированы. Ручной ввод допускается только в демонстрационном режиме.

## Проверенные источники

1. **ФНС / Государственный адресный реестр (ГАР/ФИАС)** — официальный классификатор адресов, субъектов и населённых пунктов, с версиями и регулярными выгрузками: https://fias-file.nalog.ru/Frontend и https://www.nalog.gov.ru/opendata/7707329152-fias/
2. **Росстат / ОКТМО** — коды муниципалитетов, полезны для нормализации связей: https://rosstat.gov.ru/opendata/7708234640-oktmo
3. **Организации общего образования Невинномысска** — муниципальный перечень, опубликованный управлением образования 09.07.2026: https://gorononevinsk.ru/общеобразовательные-учреждения/
4. **Другие школы** — проверенные региональные и муниципальные перечни или юридически доступная лицензированная агрегированная база. Нельзя представлять непроверенные записи как официальные.

## Импорт

- Получить легальную выгрузку ГАР; выбрать актуальные адресные объекты типа населённый пункт и их устойчивые идентификаторы, не просто строковые названия.
- Связать населённые пункты с субъектами РФ и кодами ОКТМО; учитывать омонимы, переименования, районы, статус активности и все типы населённых пунктов.
- Получать реестры школ по утверждённой схеме (идентификатор юрлица/организации, название, адрес, город, регион, ссылка на источник, дата проверки). Проверять лицензии и правомерность импорта.
- Дедуплицировать по идентификатору и адресу, но не склеивать разные филиалы/организации, если у них самостоятельные записи.
- Поддерживать статусы `directory_only` (школа существует), `onboarding_requested`, `verified_partner`, `suspended`.
- Публичный вход в закрытое пространство разрешать только через подтверждённое школьное членство после безопасной регистрации.

**Важное отличие:** ГАР описывает населённые пункты и адреса, а НЕ даёт готовый полный перечень школ. Для перечня школ требуется второй источник. Проверку страны по тысячам муниципалитетов нельзя считать сделанной до реального импорта и сверки с источниками.

## Контроль качества

Полнота по субъекту, доля записей с идентификаторами, точность адресов, даты обновления, дубликаты названий, несовпадения района/города, исключённые/закрытые организации, исправление пользователем через верифицируемую заявку. Публикация обновлений — только после проверки контрольной выборки.
