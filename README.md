# Проект S — школьная платформа (версия 0.2.0)

Интерактивная демонстрационная версия закрытого школьного сообщества. Временный бренд заменяется через `config.js`.

## Что реализовано

- Современный адаптивный интерфейс и отдельные сценарии для телефона/компьютера.
- Главная с рекомендациями, новыми возможностями, профилями учеников и расписанием событий.
- Активности: события, клубы, проекты и команды.
- Поиск, тематические фильтры, сортировка по дате, популярности и новизне.
- **Сохранённое:** добавление активности в избранное и отдельный раздел.
- Создание активности, заявки на участие, обработка заявок, приглашения.
- Редактирование школьного паспорта, уведомления, демонстрационные обращения по безопасности.
- Обзор будущей подписки, без платежей.

## Как работает демо

Все участники и события — вымышленные. Прототип **не принимает реальные аккаунты и не отправляет данные на сервер**. Состояние демонстрации сохраняется в `localStorage` конкретного браузера; оно не синхронизируется между устройствами. Жалобы и приглашения никуда не доставляются.

## Публикация

Сайт состоит из `index.html`, `app.js`, `styles.css`, `config.js` и `favicon.svg`. Никаких сборщиков и внешних библиотек. GitHub Actions из `.github/workflows/deploy.yml` автоматически публикует ветку `main` в GitHub Pages.

## Проверки

`node --check app.js` — проверка синтаксиса.

`node tests/smoke.mjs` — основные сценарии приложения.

## Перед запуском реальной школы

Потребуются серверная авторизация, разграничение доступа между школами, обработка персональных данных в России, согласия, модерация, безопасность, резервные копии и тестирование на реальных устройствах. Пока **не используйте прототип для настоящих персональных данных школьников**.
