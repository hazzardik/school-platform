# Проект S — школьная социальная платформа (демоверсия 0.3.0)

**Сайт:** https://hazzardik.github.io/school-platform/

Временное название хранится в `config.js`. Меняется без переписывания интерфейса.

## Что доступно

- Главная страница: события, рекомендации, ученики (вымышленные данные).
- Каталог проектов, клубов, событий и команд; поиск, фильтры, сортировка.
- Создание своих проектов, приглашения, заявки и управление ими.
- Профиль, навыки, интересы, уведомления и сохранённое.
- **Мой план:** календарная лента на 7 или 30 дней, отметки возможных пересечений, экспорт в `.ics`.
- **Plus как концепция:** подбор по интересам, черновик портфолио с печатью/PDF, шаблон нового проекта и планировщик.
- **Без платных барьеров:** участие, создание проектов, поиск людей, жалобы и доступность базовых механизмов безопасности предполагаются бесплатными.

## Демо и его ограничения

Это **не действующая закрытая сеть школы**. Вводить реальные ФИО, контакты или чувствительные данные школьников нельзя. Нет настоящей регистрации, разграничения прав пользователей, синхронизации между устройствами, серверных чатов и платежей. Хранилище — `localStorage` текущего браузера; оно не является безопасной базой личных данных и может быть изменено пользователем. Жалобы и приглашения на настоящий сервер не отправляются.

Все функции Plus в демо работают **бесплатно**. Нет счёта, рекуррентной оплаты, автопродления или фиктивного статуса «подписка оформлена». Портфолио не является официальным доказательством достижений.

## Разработка и публикация

Без сборщика, внешних скриптов и серверных зависимостей. Главные файлы: `index.html`, `styles.css`, `app.js`, `config.js`, `favicon.svg`.

GitHub Actions автоматически публикует `main`. Перед развёртыванием выполняются:

```sh
node --check app.js
node tests/smoke.mjs
node tests/security-and-plus.mjs
```

## Что исправлено в v0.3

- Ограничена загрузка данных из браузерного хранилища: типы, идентификаторы, размеры строк, числовые поля, даты и допустимые статусы проверяются.
- Динамический CSS-класс активности формируется только из известных типов.
- При вступлении в проект и принятии заявки проверяется количество мест (демологика).
- Задана ограничительная политика загрузки ресурсов (CSP через HTML meta; она не заменяет серверных HTTP-заголовков).
- Добавлен тест на HTML-инъекцию из локальных данных и проверки новых функций.
- Состояние старых демопроектов сохраняется после обновления, если оно соответствует допустимой структуре.

## Безопасность настоящего продукта — следующий этап

Текущие проверки **не доказывают отсутствия уязвимостей** и не являются аудитом защищённой информационной системы. Перед реальным запуском со школьниками обязательны российское размещение персональных данных при применимости закона, юридическая проработка согласий и обработки данных несовершеннолетних, серверная идентификация и авторизация, изоляция пространств разных школ, ограничения запросов, проверка прав доступа к каждому объекту, безопасная модерация чатов, журнал действий, мониторинг и резервные копии.

Платежи и подписки вводить только после отдельной юридической проверки и тестов реального платежного провайдера.
