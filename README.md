# Проект S — демонстрационная версия школьной платформы

Работающий **адаптивный интерфейс** закрытого школьного сообщества на чистом HTML/CSS/JavaScript, без сборки и сторонних зависимостей. Один код для телефона и компьютера. Временный бренд меняется в `config.js`.

## Запуск

Откройте `index.html` в браузере. Для более корректной работы локального хранилища используйте локальный сервер, например `python -m http.server 8000`, затем откройте `http://localhost:8000`.

## Развёртывание на GitHub Pages

Создайте отдельный репозиторий и загрузите содержимое **этой папки в корень**. В репозитории откройте **Settings → Pages → Deploy from a branch → main → / (root)**. После публикации будет работать адаптивная демонстрационная версия.

## Что реализовано

- Первый вход в демонстрационный режим с выбором роли;
- Главная «Сегодня» с событиями и рекомендациями;
- Каталог возможностей с поиском и фильтрами;
- Создание проекта, события, клуба или команды;
- Заявки на вступление, отмена, принятие и отклонение заявок;
- Профили и поиск людей по навыкам, интересам, классам;
- Приглашение в проект;
- Уведомления и состояние прочтения;
- Редактирование своего профиля;
- Запросы на модерацию, демонстрационный интерфейс состояния аккаунта и обжалования;
- Информация о будущей подписке, без списаний;
- Настройки и очистка демоданных;
- Мобильная и настольная адаптивность.

## Важное ограничение

**Это не готовый к запуску школьный сервис.** Данные вымышленные и сохраняются только в браузере через `localStorage`. Это не серверная база и не реальная авторизация. Нет защищённых чатов, проверки принадлежности к школе, реальных платежей или хранения персональных данных. Не вводите настоящие данные учеников и не приглашайте реальных несовершеннолетних пользователей до подключения правомерной инфраструктуры в России, разработки документов и проверки юристом. Демо-содержимое предназначено только для проверки продукта.
